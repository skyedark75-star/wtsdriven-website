# Portfolio images

Place approved, web-ready WTSDRIVEN photography in this folder.

Suggested naming:
- `hero-main.jpg`
- `automotive-01.jpg`
- `events-01.jpg`
- `creative-01.jpg`

Use descriptive, lowercase filenames. Optimise images for the web (usually WebP or compressed JPEG), keep originals backed up elsewhere, and only publish images the photographer has permission to use.

When real images are added, update the image paths in `index.html`. The current Unsplash URLs are temporary demo imagery.
