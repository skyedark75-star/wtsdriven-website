# Portfolio images

Use the folders below to add and sort WTSDRIVEN photography.

## Where to put photos

- **Start here:** [`inbox/`](./inbox/) — upload unsorted photos here. This is the drop zone.
- **Automotive:** [`portfolio/automotive/`](./portfolio/automotive/)
- **Events:** [`portfolio/events/`](./portfolio/events/)
- **Other work:** [`portfolio/other/`](./portfolio/other/)

## Upload workflow

1. Upload your photos into `inbox/` using GitHub's **Add file → Upload files** option.
2. Tell ChatGPT you've added them and share the filenames or repository link.
3. ChatGPT can help classify the images, suggest tidy filenames, and move them into the correct portfolio folders.
4. Once sorted, the website's portfolio image paths can be updated to use the new files.

Use descriptive, lowercase filenames (for example, `bmw-m3-night-meet-01.jpg`). WebP or compressed JPEG is usually suitable for website copies; keep your full-resolution originals backed up elsewhere.

Only upload and publish images you own or have permission to use. The current Unsplash URLs on the website are temporary demo imagery and still need replacing.
