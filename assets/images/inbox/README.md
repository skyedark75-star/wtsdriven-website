# Photo drop zone

Upload your original photography into this folder first.

## How to add photos
1. Open the repository on GitHub.
2. Go to `assets/images/inbox/`.
3. Choose **Add file → Upload files**.
4. Drag in your photos and commit the upload.

Use clear filenames if possible, for example:
- `bmw-m3-night-meet.jpg`
- `rolling-road-event-01.jpg`
- `brand-shoot-behind-scenes.jpg`

You can upload a batch without sorting it first. Then tell ChatGPT the filenames (or share the repository link) and it can help classify them, rename them consistently, and move them into the portfolio folders.

Please upload only photos you own or have permission to use. Keep original, high-resolution files; web-sized copies can be made later.
